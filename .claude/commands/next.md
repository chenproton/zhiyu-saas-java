# /next - 下一步建议

基于当前项目状态，给出接下来该做什么的具体建议。

## 执行

1. 了解上下文：当前任务台账（激活 `task-tracker`）、最近 git 提交、未提交改动、TODO。
2. 分析当前所处阶段（需求/设计/开发/联调/测试/部署）。
3. 给出 **3 条以内**可立即执行的下一步，每条含：
   - 做什么（具体到模块/文件/接口）
   - 为什么（依赖关系/价值）
   - 用哪个技能或命令（如 `crud-development`、`/crud`、`bug-detective`）
4. 标注阻塞项（需要用户决策或外部依赖的）。

## 原则

- 建议要具体可执行，不空泛。
- 优先解除阻塞、补齐主链路，再做增强。
- 涉及 6.x 约定时对齐 `code-patterns`。
