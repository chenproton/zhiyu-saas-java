# 知与 SaaS 系统功能清单（当前版本）

> 依据当前代码整理（后端 `backend/internal/router/*` 全部路由注册、前端页面树 `apps/edu/app/**`、统一导航 `apps/edu/lib/navigation-config.ts`、数据库 migrations），**仅包含当前代码中已实现的功能**。

## 一、总体架构

1. **SaaS 多租户**：多学校共平台，账号名按租户隔离（同一用户名不同学校可并存，登录时自动区分），全部业务数据按租户隔离；租户可停用（数据保留可恢复）、可设置起止有效期（有效期外禁止登录）、可删除（需手动输入租户名确认）。
2. **多端体系**：
   - 教育端（portal）：学校管理员 / 教师 / 学生
   - SaaS 运营端（superadmin）：平台管理员
   - 企业端（partner）：企业管理员 / 企业成员（含专家账号）
   - 公开前台：联盟展示页、各平台大厅、学习/测评页（学生端）
3. **统一认证与权限**：账号密码登录（HS256 JWT，7 天），登录限流（IP 30 次/分钟）、防爆破验证码（连续输错 3 次触发、新设备首次登录必须校验）、多租户账号选择（select-tenant）；三端 token 平台隔离；按角色（学校管理员/教师/学生/企业导师/企业管理员/企业成员/平台管理员）+ 菜单权限（控制侧边导航与按钮级操作）控制访问；多角色绑定。
4. **统一内容状态机**：岗位/场景/课程/题库/试卷五类内容资源统一六态生命周期——草稿 → 审批中 → 待发布（已通过）→ 已发布 → 已归档，另有 已驳回 状态；统一操作：新建、编辑、提交审批、审批（通过/驳回）、发布、取消发布、撤回审批、保存草稿、邀请共建、归档、克隆。人培方案/教学计划为两态简化（draft/published、draft/confirmed），共用统一动作入口；题目随题库/试卷整体流转。
5. **统一审批流**：多步骤审批流程模板（每步含步骤名称、审批角色，至少 1 步），各平台共用；审批中心（待我审批/已通过/已驳回筛选、审批数据看板、批量通过/驳回、自动绑定批次分组）；有待办审批单的流程禁止删除；提交/审批均加锁防重复触发。
6. **批次分组管理**：岗位/场景/课程/题库/测评/教务等模块均有批次分组，批次绑定审批流程后其下资源自动引用；资源调整批次不触发重新审批。
7. **内容快照版本固化**：岗位/场景/课程/题库/试卷发布时自动保存"当时的完整内容"快照；学习、成绩、评分、排课、考试安排均对照快照版本，改版不影响历史数据；有成绩或使用中的内容禁止删除；内容每次发布版本号自动 +0.1（满 10 进位）。
8. **统一编码**：岗位/场景/题库/题目/试卷/课程/知识点/能力点自动生成编码；资源编码规则可维护。
9. **导入导出模板体系**：岗位/场景/体系课/颗粒课/题库/题目/试卷/行业/专业/组织/学生/教师/排课/方案课程/教务配置/联盟（项目/成果/协议/品牌）等 Excel 模板下载、批量导入（两步导入：预览+确认、重名处理含"新增并导入"、覆盖确认、防重复）与导出。
10. **文件服务**：上传类型白名单、拖拽上传、在线预览（file-viewer 浏览器原生渲染，覆盖 208 种扩展名含 office/pdf/压缩包等；file-viewer 不支持的格式回退 kkFileView 兜底）、签名 URL（无登录态可访问）、图片墙展示；文件按租户隔离，跨租户访问控制。
11. **安全与审计**：登录/操作日志全量审计（操作日志异步化）、敏感信息脱敏（身份证号等）、考试防作弊（切屏/失焦/退出全屏提醒、答题页禁复制/右键、刷新需确认）、跨租户越权防护、登录/上传/导入导出/AI 对话/密码写/公开读取限流（明细见 `docs/security-standards.md`）。
12. **多端适配**：PC + 移动端响应式（编辑页/列表页/展示页/系统管理全适配）、中英双语切换、主题色体系（全平台商务蓝，支持租户级/全局配置）、全局字号调节、顶部导航移动端访问二维码、页面分享二维码。

## 二、体系框架（业务模型）

1. **岗位能力模型**：以职业岗位为牵引，岗位 → 工作职责 → 能力领域 → 能力点（编码、胜任标准、能力等级）结构化建模，支持岗位名称、别名、所属行业、适用专业、薪资范围、发展路径、关联证书等配置。
2. **场景任务模型**：场景 → 任务链（顺序可拖拽、依赖任务、训练/考核类型、难度、预估学时）→ 考查知识点（关联颗粒课）→ 考查能力点（来自岗位能力模型）→ 配套资源（11 类）→ 测评形式（现场问答/现场评审/试卷/题库）→ 评价规则与评价标准（量规/评分规则）。
3. **评价认证模型**：场景任务评价、课堂节点评价、课程评价、在线考试、日常考试等多源评价数据汇聚 → 学生能力画像 → 按岗位能力认证规则（两段权重、能力点五档评级）计算能力达成结果，支持每日定时自动汇聚。
4. **数据贯通模型**：岗位反查场景、场景反查能力点与知识点、学生画像反查学习与评价过程（快照追溯）；知识图谱可视化场景→任务→知识点关联；认证结果与能力画像供联盟品牌展示调用。
5. **多主体协同**：学校管理员、教师、学生、企业导师、企业管理员、企业成员、专家、平台管理员多角色参与平台建设与教学运行。
6. **专业拓展能力**：专业、行业字典独立维护并支持批量导入，岗位/场景/课程均可关联适用专业与行业，支持从现有专业向新专业方向扩展。

## 三、职业岗位学习平台（job）

### 1. 岗位资源库
- 分区导航：我的岗位、共建岗位、公共岗位库；搜索栏；视图切换（列表/分组）
- 列表视图展示未归入批次的岗位；分组视图按批次分组展示
- 批次分组管理（新建批次、绑定审批流程、全局引用审批流）
- 审批流程管理（新建/管理/应用于岗位审批）
- 资源审批管理：审批数据看板（待处理/已通过/已驳回/总数）、审批搜索、待我审批/已通过/已驳回筛选、待审批岗位列表

### 2. 岗位信息管理
- 基础信息：岗位封面、名称、别名、所属行业、创建人/共建人、薪资范围等
- 岗位概况：岗位简介与职业发展说明
- 岗位职责：任职要求与岗位职责（职责描述、编码、关联能力点数统计、能力点详情查看）
- 涉及证书：展示岗位关联证书样本
- 能力模型展示：按能力领域、能力点结构化、可视化展示（帮助学生建立岗位能力全局观）
- 胜任标准展示：按能力领域、能力点全览各能力点的胜任标准（掌握等级划分、目标等级、标准描述），提供领域导航菜单快速定位

### 3. 岗位能力模型管理
- 新增岗位：岗位名称、别名、所属行业、适用专业、薪资范围、简介、封面、所属批次、当前版本、共建人选择等
- 添加工作职责、任职要求、发展路径、涉及证书
- 配置能力模型：拆解能力领域、拆解能力点、配置能力点胜任要求
- 提交审批、预览岗位（未发布可前台预览）、保存草稿
- 岗位编辑页完整保存（职责/证书/能力点/封面上传）；工作职责弹窗批量添加
- 岗位克隆（一键复制全部关联数据）、岗位归档与恢复

### 4. 岗位展示大厅（前台）
- 数据看板：平台收录岗位数、近期上新、岗位覆盖行业数、岗位资源浏览人次
- 标签式导航栏（按专业/行业分类快捷筛选）；排序（默认/最近收录/最多点击）；搜索（名称/编码）
- 岗位卡片列表（版本号、更新日期、封面、编码、名称、能力点数、行业专业标签、创建人/共建人、浏览人次）；岗位详情页（内容+能力模型+快照版本）
- 岗位收藏（本人可见、真实收藏数统计与排行榜）

### 5. 岗位进阶功能
- 岗位推荐管理（推荐岗位配置，热门标签与岗位推荐打通）
- 学习路径管理（学习路径列表/编辑，关联岗位序列与真实场景，学生端学习路径对接真实场景）；岗位落地页「实践场景」tab 与学习页场景排序统一按学习路径步骤顺序（规则见 `apps/edu/lib/learn-road-order.ts`，两页一致、受 /job/learn-roads 管理）
- AI 辅助编写（AI 生成岗位内容并直接写入表单字段，可逐字段恢复上版/全部撤销，服务端不落库）
- 岗位快照版本、Excel 批量导入导出、岗位详情分享二维码

## 四、实践场景学习平台（scene）

### 1. 场景资源库
- 场景资源列表（卡片/列表，全部/我的/共建/公共，状态：草稿/审批中/待发布/已驳回/已发布）
- 场景新建（自动生成场景编码）、编辑（草稿/待发布/已驳回/已发布均可编辑，已发布编辑后重新发布生成新版本）、克隆（生成"原名称(克隆)"新草稿）、删除（已发布不可直接删）
- 批次分组调整（不触发重新审批）；批量导入（xlsx 模板生成草稿场景）、导出（Excel）

### 2. 场景任务配置（场景编辑）
- 基础信息：场景名称、场景编码（自动）、版本号（自动管理）、目标岗位、所属批次、面向行业、适用专业、难度等级、场景介绍、场景封面、创建人、共建人/共建部门
- 任务链配置：新建/克隆/引用三种方式引入任务，按顺序箭头连接可视化展示、拖拽调整顺序
- 任务基础信息：任务名称、任务编码（自动）、任务类型（训练任务/考核任务）、预估学时、难度、背景介绍、详细描述、依赖任务
- 任务说明：长文本结构化任务说明书（任务目标/交付要求/测评要求），全屏编辑模式
- 考查知识点：从知识点库引用/克隆/新增，知识点可关联本系统颗粒课
- 考查能力点：从岗位能力模型选择；须先关联目标岗位（未关联锁定并提示）
- 任务资源：11 种资源类型（文档/表格/图片/音频/视频/压缩包/链接/场地/设施设备/软件/其他）差异化字段配置
- 测评形式：现场问答、现场评审、试卷、题库四种，可多选；未开通形式展示"未开通"水印
- 评价规则：针对已选测评形式分别配置测评对象、评分主体、测评资源、评价标准
- 任务权重：弹窗/总评规则页统一编辑，任务权重之和必须等于 100%

### 3. 测试方式配置（任务级测评资源与答题规则）
- 现场问答（随机抽题）：抽题方式（系统随机分配/老师手动选择）、抽题数量、现场要求（提交材料要求、场地资源）、评价量规或评分规则
- 现场评审：提交材料要求、场地资源、截止天数、允许重复测评、评审步骤（默认学生自评/小组互评/教师评审，可自定义增删改、企业导师步骤可指定评分人）、评价量规或评分规则
- 试卷：从试卷库搜索选择或新建试卷、试卷权重；考试时长/及格分数/重考/乱序/成绩展示/激活方式等配置见试卷管理
- 题库：答题方式（全部作答/自由刷题）、正确率（自由刷题时超过正确率得满分）、时间限制、重考规则（允许/次数）、乱序、成绩展示、激活方式（随时/定时）、题目分值配置
- 成果评价/作业/随堂测（课程节点侧）：材料要求、截止天数、场地资源、允许重复提交；作业/随堂测还支持时间限制、重考、乱序、成绩展示与激活方式

### 4. 评价规则配置
- 测评对象：个人/小组两种方式
- 评分主体：教师、企业导师独立开关控制
- 教师评分：专业背景、评分人数、多人记分规则（平均/中位数/最高/最低）、权重占比、最低教龄
- 企业导师评分：专业领域、最低工作年限、岗位工作经历、评分人数、多人记分规则、权重占比
- 评分主体权重校验：各主体权重占比之和必须等于 100%，不满足阻断保存并提示

### 5. 评价标准配置
- 评价量规：评价维度（多条）、关联能力点、关联知识点、等级转换规则（名称/颜色/分数区间/备注）、维度权重（加和须 100%）
- 评分规则：评价项（多条）、加减分规则、分值，一键均分总分 100 分
- 评价标准模板：量规/评分规则均可保存为模板、一键覆盖当前配置、删除模板

### 6. 场景审批与发布
- 审批流程模板：预设审批流（流程名称、说明、动态审批步骤、审批角色，至少 1 步）
- 提交审批：无批次手选审批流程，有批次自动使用关联流程；提交后草稿→审批中
- 审批操作：通过（可填意见）→待发布；驳回（原因必填）→已驳回
- 发布/取消发布：待发布→已发布（学生端可见）；已发布→待发布（学生端不可见）
- 撤回审批：审批中由创建者撤回至草稿

### 7. 场景大厅（前台）
- 数据看板：收录场景总数、近期上新、场景覆盖行业数、累计浏览人次
- 标签导航（专业/行业）、排序（默认/最近收录/最多点击）、搜索（名称/编码）
- 场景卡片列表（版本号、收录/更新日期、封面、编码、名称、设计能力点数、关联任务数、行业专业标签、创建人/共建人、浏览人次）

### 8. 场景详情（前台）
- 场景概况：简介、背景意义、学习目标
- 任务概览：任务卡片（名称、类型、测评方式、预估学时、难度、知识点数、能力点数、资源数）
- 资源中心：聚合所有任务配套资源，按 11 种类型分组展示
- 能力模型：按能力领域分组展示场景覆盖的能力点（来自任务能力点配置与岗位平台）
- 评价标准：按任务卡片展示每个任务的测评方式配置与权重占比（共 N 个评价配置）
- 知识图谱：场景节点（紫）→任务节点（绿，可点击）→知识点节点（黄，可点击）可视化，节点交互、拖拽与缩放

### 9. 场景任务学习/测评（学生端）
- 学习面板：任务说明卡片（长文本全屏）、知识点标签（点击查看详情，展示关联颗粒课）、能力点标签、交付要求、配套资源列表
- 单元测评区：按任务配置的测评形式动态渲染测评入口卡片（试卷/题库跳转作答等），展示各形式已完成数与汇总得分，支持提交与状态（待评分/已评分）展示
- 提交栏：未提交时展示各测评形式完成状态与确认提交；已提交展示成功状态与提交摘要；提交后进入"待评分"不可再修改
- 全局资源侧边栏：右侧滑出面板（知识点/能力点/资源 3 个 Tab），右下角固定触发按钮唤起

### 10. 其他
- 等级映射配置（grade-mappings）、场景归档管理、共建场景（企业端共建后由学校发布）、场景克隆、快照版本、批量导入导出、分享二维码

## 五、能力测评认证平台（evaluation）

### 1. 测评体系
- 测评方式：系统内置 7 种测评方式——现场问答（随机抽题）、现场评审、试卷、题库、成果评价、作业、随堂测；场景任务配置时按需多选（未开通形式展示"未开通"水印），见第四章第 3~5 节的任务级测评形式与评价规则配置
- 企业共建端可读取学校测评方式列表（供共建场景任务引用，见第十章）
- 测评结果查看：场景任务评价、课程节点评价、日常考试评价三大评分入口

### 2. 题库管理

## 十三、AI 智能服务（ai）

1. **AI 底座（AIService）**：统一 LLM 调用层（禁止各模块自行封装底层调用）；租户 AI 服务配置（申请开通、API 密钥加密存储、永不回传前端/不打日志）；统一错误映射（未配置 → 412 ai_not_configured 引导前端到租户配置页；上游错误 → 502 + 上游 message；其余 → 500）
2. **AI 助手对话**：租户内任意登录用户可用，非流式对话（一次性返回全文）；请求上限（messages ≤ 50、单条 ≤ 8000）；不自动重试
3. **AI 辅助表单填写**：岗位 AI 辅助编写、场景 AI 辅助编写（基础信息/任务卡片/任务链），AI 生成内容直接写入表单字段（可逐字段恢复上版/全部撤销），服务端不落库
4. **AI 用量看板**：AI 调用记录、租户用量统计（饼图占比）、AI 套餐 token 额度展示（额度不强制拦截，防滥用靠每用户限流）
5. **AI 智能服务中心**（详细 spec 见 `docs/spec/ai-service-center.md`）：
   - **知识库**：教师/学生自建知识库（私有默认），文档上传解析（pdf/docx/txt/md，≤10MB，纯 Go 解析，分块入 pg_trgm 索引），协作者共建（editor 可编辑/viewer 只读），库内流式问答（带资料溯源）
   - **智能体**：自定义名称/头像/开场白/system_prompt + 关联 ≤5 个知识库；SSE 流式对话（统一走 AIService，412 未配置引导）；多会话管理（会话持久化、历史窗口 10 条）；回答引用资料溯源展示
   - **AI 广场**：已发布知识库/智能体的租户内共享广场（搜索/标签/热度排序），一键使用智能体对话、知识库问答；收藏（复用通用收藏，类型 ai_kb/ai_agent，仅已发布可收藏）
   - **发布审核**（school_admin）：知识库/智能体发布需审核（通过/驳回必填理由/下架），审核日志留痕；下架后广场即时不可见
   - **第三方挂接**（school_admin）：挂接第三方智能体/应用为纯链接卡片（名称/图标/描述/URL/排序/上下架，URL 仅 http/https），广场展示点击新窗口打开
   - **安全锚点**：分块检索 SQL 内嵌可见性过滤（published ∨ 拥有者 ∨ 协作者），私有知识库永不通过已发布智能体泄露给无权限用户
