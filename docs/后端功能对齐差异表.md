## 三、开发计划（按依赖顺序）

1. **第一批（并行 3 子代理）**：A 导入导出模板全套；B+C+E+G+I 小域集合；F+H 认证与文件通道
2. **第二批（1 子代理）**：B 联盟/partner 短路径对齐（验证 Java /partner 前缀实现与 Go 路径差异，改路径或加别名）
3. **第三批（并行）**：语义简化项补齐（lesson hooks、alliance/register 角色、system 菜单 RBAC 种子、改密失效、验证码）
4. **验证**：端点复查（重跑归一化 diff → 0 缺失）+ 编译 + 部署 + 分域冒烟
5. **收敛**：更新本表状态，汇报

## 四、验收标准

- 归一化端点 diff：缺失 = 0（Go 737 条全部有 Java 对应）
- 编译通过 + 部署冒烟（登录/列表抽样 200）
