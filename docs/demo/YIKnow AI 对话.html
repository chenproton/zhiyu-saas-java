专业代码：530802

二、入学要求

三、修业年限

基本修业年限：三年

弹性修业年限：2.5-5年

五、培养目标与培养规格

（一）培养目标

本专业培养理想信念坚定，德、智、体、美、劳全面发展，具有一定的科学文化水平、良好的人文素养、职业道德和创新意识，精益求精的工匠精神，较强的就业能力和可持续发展的能力；掌握现代物流管理专业知识和技术技能，面向道路运输业、多式联运和运输代理业、装卸搬运和仓储业、邮政业等行业的管理（工业）工程技术人员、装卸搬运和运输代理服务人员、仓储人员等职业群，能够从事仓储、运输与配送、采购、供应链管理等基层管理及物流服务等工作的高素质技术技能人才。

（二）培养规格

💡 素质目标
  1. 坚定拥护中国共产党领导和我国社会主义制度
  2. 践行社会主义核心价值观，具有深厚的爱国情感和中华民族自豪感
  3. 具有良好的职业道德和职业素养
  4. 具有精益求精的工匠精神
  5. 具有较强的集体意识和团队合作精神
  6. 具有良好的身心素质和人文素养
📚 知识目标
  1. 掌握必备的思想政治理论、科学文化基础知识和中华优秀传统文化知识
  2. 熟悉与本专业相关的法律法规以及环境保护、安全消防等相关知识
  3. 掌握现代物流管理的基本理论和专业知识
  4. 掌握仓储作业、运输作业、配送作业的操作流程及规范
  5. 掌握采购与供应链管理的基本理论与方法
  6. 了解智能物流技术及其应用
🔧 能力目标
  1. 具有探究学习、终身学习、分析问题和解决问题的能力
  2. 具有良好的语言、文字表达能力和沟通能力
  3. 能够进行仓储作业管理，包括入库、在库、出库等环节的操作与管理
  4. 能够进行运输与配送作业管理，包括运输方式选择、路线规划、配送调度等
  5. 能够进行采购管理，包括供应商选择、采购谈判、采购合同管理等
  6. 能够运用信息技术进行物流数据分析与处理

八、实施保障

（一）师资队伍

本专业专任教师与兼职教师之比为3:1，"双师型"教师占专业课教师比例达到60%以上。专任教师具有高校教师资格，具有物流管理或相关专业本科及以上学历。

（二）教学设施

🏢 校内实训基地
  • 智能仓储实训中心（含AGV、立体货架、WMS系统）
  • 物流信息技术实训室
  • 供应链沙盘模拟实训室
  • 电子商务物流实训室

九、毕业要求

学生须修满本专业人才培养方案规定的学时学分，完成规定的教学活动，符合以下条件方可毕业：

  1. 思想品德考核合格
  2. 修满 140 学分
  3. 完成顶岗实习并考核合格
  4. 取得至少1个与专业相关的职业技能等级证书
