## 0. 结论摘要

| 指标 | 数值 |
|---|---|
| React 路由页（page.tsx） | **186** |
| Vue 路由条目（path） | **227**（含 14 条 `redirect`：12 条为多余清单 D 类重定向 shim，2 条为根 `/` 与 `''` 重定向；实际页面路由约 213） |

## 五、待决策项结论（community / favorites）

**核对结果：**
1. Vue 存在独立路由 `/portal/community`（`router/index.ts:145`）与 `/portal/favorites`（`router/index.ts:150`），分别渲染 `src/views/portal/community.vue` 与 `src/views/portal/favorites.vue`。
2. React 中无这两个独立路由；社区内容在 workspace 学生 Tab 的 `CommunityTab`（`?tab=community`），收藏内容在 `CareerTab`（「我的收藏」）。
3. Vue 侧 **workspace 同样已实现这两个 Tab**：`src/views/portal/workspace/CommunityTab.vue`、`src/views/portal/workspace/CareerTab.vue`，即内容并未缺失，只是额外多了两个独立路由。
4. **入口引用核查**：全库 grep `portal/community`、`portal/favorites` 的导航引用 —— **无任何 `router.push('/portal/community')` 或 `<router-link to="/portal/favorites">`**。仅命中：`router/index.ts` 的路由定义本身；`src/api/portal.ts:56-66`（后端 API 路径 `/portal/community/topics`，属接口路径非前端路由）；`CareerTab.vue:9` 注释提到 favorites.vue 的实现思路。`community.vue`/`favorites.vue` 内部无对外入口。

**结论：** `/portal/community` 与 `/portal/favorites` 是两个 **「孤儿路由」（无入口引用的独立页面）**。内容已由 workspace 的 CommunityTab/CareerTab 覆盖。**移除它们不会产生死链**（当前无任何页面链接到这两条路径）。建议：若确认 workspace Tab 已充分覆盖，可删除这两条路由及其两个独立 `.vue` 文件；若需保留独立入口，应至少在一处导航（如 workspace 或 portal 首页）补上链接，否则纯属无入口死路由。**建议移除**（默认）。
