# 排课功能测试 Mock 数据

本目录包含一套逻辑闭环的 mock 数据，用于在一个全新租户上完整测试教务排课流程。

## 导入顺序（严格按此顺序）

| 步骤 | 文件 | 导入位置 |
|------|------|---------|
| 0 | `1-专业导入.xlsx` | 系统管理 → 专业管理（可选，若系统已内置专业可跳过） |
| 1 | `2-组织架构导入.xlsx` | `/portal/apps/system/org-user/org-structure` |
| 2 | `3-教师导入.xlsx` | `/portal/apps/system/org-user/teachers` |
| 3 | `4-岗位导入.xlsx` | `/job/positions` |
| 4 | `5-场景导入.xlsx` | `/scene` |
| 5 | `6-体系课导入.xlsx` | `/lesson/admin/system` |
| 6 | `教务配置数据.xlsx` | `/affairs/config`（学期/场地/节次） |
| 7 | `7-方案课程导入.xlsx` | `/affairs/programs/` 中新建方案后导入 |
| 8 | 生成教学计划 → 确认 → 进入排课 | `/affairs/teaching-plans` |
| 9 | `8-排课导入.xlsx` | `/affairs/scheduling` → 导入批量排课结果 |

## 数据规模

- **专业**：2 个（人工智能技术应用、软件技术）
- **组织架构**：1 学校 + 1 学院 + 2 专业 + 10 班级
- **教师**：10 名（T001~T010）
- **岗位**：20 个（每个含 2 个能力点）
- **场景**：40 个（20 岗位 × 2 场景，每个场景 2 个任务，共 80 任务）
- **体系课**：15 门（仅课程名称，无内容）
- **学期/场地/节次**：复用 `docs/教务配置数据.xlsx`（3 学期 × 12 场地 × 10 节次）
- **排课方案**：55 条（40 场景 + 15 体系课），覆盖周一~周五、全节次、教师/场地/班级轮转

## 关联关系（已保证闭环）

- 场景 → 岗位：40 个场景分别关联 20 个岗位，每个岗位 2 个场景
- 任务 → 能力点：场景任务引用的能力点（`<岗位>核心技术能力`、`<岗位>团队协作能力`）均由岗位导入自动创建
- 排课 → 教师/场地/班级/节次：均引用前序步骤已导入的对象
- 人培方案：20 岗位 + 8 体系课

## 使用提示

- 导入岗位后需发布岗位，场景引用岗位能力点才能生效
- 生成教学计划后确认，再进入排课
- 排课导入会**先清空当前学期排课**再按 Excel 重新生成
- 场地名称与 `教务配置数据.xlsx` 完全一致（如 `博学楼 101 教室`），节次为 `上午第一节课` 等
