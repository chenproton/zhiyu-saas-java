# 校企合作联盟（alliance）批量导入 Mock 数据模板

本目录提供 5 个校企合作联盟模块的**批量导入模板（含 mock 示例数据）**，数据相互关联，
便于一次性导入一套完整的演示数据。

## 模板清单

| 文件 | 对应页面 | 对应导入类型 |
|------|----------|--------------|
| `01-合作企业导入模板-mock数据.xlsx` | `/portal/apps/alliance/enterprises` | `alliance-enterprises` |
| `02-合作项目导入模板-mock数据.xlsx` | `/portal/apps/alliance/projects` | `alliance-projects` |
| `03-合作成果导入模板-mock数据.xlsx` | `/portal/apps/alliance/achievements` | `alliance-achievements` |
| `04-合作协议导入模板-mock数据.xlsx` | `/portal/apps/alliance/agreements` | `alliance-agreements` |
| `05-专家资源导入模板-mock数据.xlsx` | `/portal/apps/alliance/experts` | `alliance-experts` |

每个文件的 Sheet 名称与表头均与系统「下载批量导入模板」生成的格式一致（第 1 行填写说明、第 2 行表头、第 3 行起为数据），可直接上传导入。

## 导入顺序

为保证关联数据完整，建议按以下顺序导入（各表单相互独立，先导入任一表单均可，但按此顺序
名称引用关系最直观）：

1. `01-合作企业` → 2. `04-合作协议` → 3. `02-合作项目` → 4. `03-合作成果` → 5. `05-专家资源`

## 表头与填写说明

模板中**青蓝色表头**列为「关联参考列」（`关联企业名称`、`关联项目名称`、`关联成果名称`、
`关联协议名称`、`关联专家姓名`、`牵头人`、`擅长领域` 等），用于表达跨表单关联关系，
**多值用中文分号「；」分隔**。

> 说明：当前版本的批量导入仅写入各实体的基础字段（第 1 行说明中列出的列），
> 「关联参考列」在导入时会被忽略，不产生实际关联数据；其作用是为 mock 数据提供统一的
> 命名引用，供演示数据串联与后续扩展关联导入能力时使用。
> 基础字段（如企业类型、合作状态等）的取值与字典映射，均与系统「下载批量导入模板」中的说明一致。
