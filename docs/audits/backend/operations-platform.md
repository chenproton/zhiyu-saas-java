# SaaS 运营与商城平台审计

> **⚠️ 部分废弃**：商城（机构/订单/提现/平台横幅）相关 handler 与前端源码已随商城下线移除，对应检查点归档；订阅管理与统计接口仍在使用。

## 核心决策

- **订阅管理**：`SubscriptionHandler` 管理租户订阅套餐，支持查询当前租户订阅和平台管理员更新订阅信息。按 `tenant_id` 过滤，每个租户只能看到自己的订阅。超管控制台通过 `/api/v1/admin/tenants/{tenantId}/subscription` 查看与更新指定租户订阅（详见 `tenant-org.md`）。
- **统计数据**：`StatsHandler` 提供平台仪表盘统计（机构数、资源数、GMV、订单数、提现待处理）和平台配置管理，以及机构自身收入统计。**其中机构/资源/订单/提现统计依赖的商城数据源已下线，`/stats/me` 目前无前端消费方。**
- ~~平台横幅 / 机构管理 / 订单管理 / 提现管理~~：handler 已随商城源码移除（2026-08-03 确认），待商城重启后重新审计。

## 风险与约束

- 订阅相关接口无跨租户风险（租户过滤 + 平台隔离中间件已覆盖）。
