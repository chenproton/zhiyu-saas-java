# 数据基础设施审计

## 核心决策

- **文件上传**：
  - multipart 上传，最大 100MB。
  - **不限制扩展名**：业务要求任务资源/资源库等模块的“其他资源”支持任意格式上传，已移除扩展名白名单。
  - 文件保存为 `<UUID>.ext`，返回 `/uploads/<filename>` 路径。
  - `Serve` 接口含路径穿越防护。
- **文件预览**：`Preview` 接口通过 LibreOffice headless 转换 Office 文件，支持 HTML/PDF/PNG 三种格式，转换后清理临时目录。
- **数据导出**：CSV 格式，支持 5 种实体（题库/试卷/课程/岗位/场景），最多 1000 行。
- **数据导入**：解析 CSV，仅提取 `name` 和 `code`，使用预定义 INSERT 语句。
- **登录日志**：支持按用户、状态筛选，租户隔离。
- **操作日志**：支持按用户、模块、动作筛选，租户隔离。
- **平台配置**：`platform_configs` 表存储 `platform_fee_rate` 和 `min_withdrawal_amount`。
- **Excel 模板系统**：`TemplateHandler` 为各业务模块（岗位/场景/课程/题库/试卷/题目/行业/专业/组织/学生/教师）提供标准化 Excel 导入模板下载。模板包含多 sheet（基本信息+明细+字典参考），字典 sheet 从数据库实时查询预填充。所有模板生成方法均需认证（`CurrentUser(r)` 非 nil）和租户隔离（`requireTenant`），通过 `excelize` 库在内存生成 Excel 并流式写入 HTTP 响应。模板内容为纯结构化数据，无公式注入风险。

## 检查点

| 检查点 | 结论 | 说明 |

| 文件预览 | PASS | LibreOffice headless 转换；HTML/PDF/PNG 三种格式 |
| 文件访问 | PASS | `/uploads/{filename}` 路径 |
| 数据导出 | PASS | CSV 格式；5 种实体；流式输出 |

| 操作日志 | PASS | 租户隔离；分页查询 |

## 风险与约束

- **文件上传无内容校验**：已移除扩展名限制，且不验证文件内容真实性。—— **低危，按\u201c简单优先、小概率异常容忍\u201d原则当前不做强制要求；若业务后续需要防伪或合规校验，可再按需引入 MIME 校验或文件头扫描。**
- **模板生成大数据量查询**：`queryDicts` 方法一次性执行 7 次字典表全表查询（行业/专业/证书/岗位/知识点/能力点/资源），租户数据量大时可能影响模板下载速度。—— **低危，模板下载为低频操作，当前可接受；若未来字典表数据量增长，建议加分页或缓存。**
- **模板无文件下载频率限制**：当前无速率限制或并发控制，恶意用户可高频请求模板下载消耗服务器资源生成 Excel。—— **低危，按\u201c容忍 hacker 行为\u201d原则当前不做防范。**
